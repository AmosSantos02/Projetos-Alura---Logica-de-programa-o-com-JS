## 📁 Projetos

---

### 🎲 AluGames
**Sistema de gerenciamento de aluguel de boardgames**

O usuário pode alternar o status de cada jogo entre `Disponível` e `Alugado` com um clique. A interface atualiza automaticamente o botão e aplica um estilo visual diferente à capa do jogo.

**Conceitos praticados:**
- Manipulação de DOM com `getElementById` e `querySelector`
- Alternância de classes CSS com `classList.add/remove/contains`
- Lógica condicional com `if/else`

---

### 🎁 Amigo Secreto
**Organizador de sorteios com embaralhamento inteligente**

O usuário adiciona os participantes e o sistema realiza o sorteio automaticamente, gerando os pares de forma aleatória e exibindo quem tira quem. Conta com validações para evitar nomes duplicados e a possibilidade de reiniciar o sorteio.

**Conceitos praticados:**
- Arrays e métodos: `push`, `includes`
- Algoritmo de embaralhamento **Fisher-Yates**
- Manipulação de listas no DOM com `innerHTML`
- Validações com `alert` e retorno antecipado

---

### 🛒 Carrinho de Compras
**Simulação de carrinho interativo com cálculo em tempo real**

O usuário seleciona um produto, define a quantidade e o sistema calcula o subtotal e o total geral da compra, adicionando os itens à lista do carrinho dinamicamente. Há também a opção de limpar tudo.

**Conceitos praticados:**
- Operações matemáticas e acumulação de valores
- Inserção dinâmica de conteúdo com `innerHTML`
- Controle de estado com variáveis globais

---

### 🎟️ Compra de Ingressos — e-Ticket
**Sistema de venda com controle de estoque em tempo real**

O usuário escolhe o tipo de ingresso (Pista, Cadeira Superior ou Inferior) e a quantidade desejada. O sistema verifica se há disponibilidade e, em caso positivo, subtrai do estoque e atualiza a interface imediatamente.

**Conceitos praticados:**
- Objetos JavaScript para armazenar dados estruturados
- Acesso dinâmico a propriedades com notação de colchetes `obj[chave]`
- Validações com `alert` e atualização de DOM

---

### 🔢 Sorteador de Números
**Gerador de números aleatórios únicos dentro de um intervalo**

O usuário define quantos números quer sortear e o intervalo (de X até Y). O sistema garante que nenhum número se repita no resultado usando um laço de verificação. O botão de reiniciar só é habilitado após o primeiro sorteio.

**Conceitos praticados:**
- Geração de números aleatórios com `Math.random` e `Math.floor`
- Laço `while` com verificação de duplicatas usando `includes`
- Controle de estado visual com `classList`
